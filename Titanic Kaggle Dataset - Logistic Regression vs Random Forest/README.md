# 🚢 Titanic — Analisi Esplorativa e Modello Predittivo

## Obiettivo
Analisi del dataset Titanic per identificare i fattori che influenzavano 
la sopravvivenza dei passeggeri, con sviluppo di un modello predittivo.

## Cosa ho fatto
- Pulizia dei dati (gestione valori mancanti)
- Analisi esplorativa (EDA) con visualizzazioni
- Analisi delle correlazioni tra variabili
- Modello di classificazione con Logistic Regression (82.68% accuracy)
- Confronto con Random Forest
- Valutazione con Confusion Matrix

## Principali insight
- Il sesso è il predittore più forte (donne: 76% vs uomini: 19%)
- La classe del biglietto è il secondo fattore più importante
- L'età da sola ha basso potere predittivo
- La Logistic Regression supera la Random Forest su questo dataset

## Tecnologie
Python · Pandas · Seaborn · Matplotlib · Scikit-learn
